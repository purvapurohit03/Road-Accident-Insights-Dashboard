# 🚗 Road Accident Insights Dashboard

## Project Overview
This project presents an interactive Tableau dashboard designed to analyze road accident trends, identify high-risk conditions, and provide data-driven insights to improve road safety measures.

![Dashboard Preview](dashboard_preview.png)

---

## 📊 Key Insights & Features
* **KPI Summary:** Total casualties, accident severity breakdown, and vehicle types involved.
* **Trend Analysis:** Monthly and yearly patterns identifying peak accident periods.
* **Environmental Impact:** Analysis across different road types, weather conditions, and light conditions.
* **Interactive Filtering:** Drill down by region, accident severity level, and time frame.

---

## 🛠️ Tools Used
* **Tableau Desktop** – Data visualization & dashboard design
* **Data Source:** Road accident dataset (`.hyper` / `.csv`)
